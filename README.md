🤖 AI Data Quality Checker

A simple Streamlit application that checks CSV data for common data quality issues such as missing values and duplicate rows.

🚀 Features

- 📂 Upload CSV files
- 🧪 Use sample data
- 📊 View data preview
- 🔍 Check missing values
- ♻️ Detect duplicate rows
- 📈 Display row and column counts
- ⚠️ Show data quality warnings

🛠️ Technologies Used

- Python
- Streamlit
- Pandas

▶️ How to Run

Install the required packages:

pip install -r requirements.txt

Run the Streamlit application:

streamlit run app.py

📋 How to Use

1. Open the application.
2. Select Use Sample Data or Upload CSV.
3. View the uploaded/sample data.
4. Check the Data Quality Report.
5. Review missing values and duplicate rows.

📊 Sample Output

The application displays:

- Total number of rows
- Total number of columns
- Number of duplicate rows
- Missing values for each column
- Data quality warnings
